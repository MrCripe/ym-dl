# Что нового

## 1.2.0

Первый выпуск после разбора проекта со стороны пользователя: исправлено то,
что мешало программе выглядеть и работать как нормальное приложение.

**Безопасность**

- Токен больше не лежит файлом рядом с программой: он уходит в системное
  хранилище паролей — Windows Credential Manager или Secret Service на Linux.
  Старый файл переносится автоматически и удаляется.
- Включена Content Security Policy. Раньше она была отключена совсем.

**Первый запуск**

- Музыка по умолчанию сохраняется в `~/Music/ym-dl`, а не в `~/Music/lmao`.
  Уже скачанная библиотека в старой папке подхватывается сама.
- В README появились скриншоты и блок «Скачать» в самом начале.
- Написано, зачем нужен ffmpeg, что будет без него и где его взять.
- Добавлен раздел «Если что-то не работает».

**Интерфейс**

- Кнопка «Вставить из буфера» больше не вызывает окно разрешения WebView2.
- Продвинутые настройки (сеть, лимиты, повторы) свёрнуты в раскрывающийся блок.
- Понятнее тексты: шаблон пути показывает пример результата, убраны
  формулировки вроде «стандартные теги mutagen» и «опасный режим».
- В заголовке окна и в списке программ теперь «ym-dl — Яндекс.Музыка».

**Обновления**

- Исправлен манифест обновлений: он указывал на API-адреса, которые отдают
  JSON вместо файла, поэтому «Обновить» не могло работать.
- Добавлен workflow, который правит манифест при публикации релиза.
